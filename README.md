# Перенос истории канала из Telegram в MAX

Простой консольный инструмент для переноса старых постов (текст, фотоальбомы до 10 картинок, видео, файлы, форматирование) из выгрузки Telegram-канала в канал мессенджера MAX.

### Что умеет скрипт
* Склеивает фотоальбомы из Telegram обратно в один красивый пост в MAX (до 10 фото/видео с подписью).
* Сохраняет форматирование (жирный, курсив, ссылки, код, цитаты) и добавляет в конец оригинальную дату поста.
* Автоматически разбивает длинные посты (> 4000 символов) на части.
* Запоминает место остановки: можно в любой момент прервать (`Ctrl+C`) и позже продолжить ровно со следующего поста.
* Не изменяет исходные файлы архива Telegram — все логи и прогресс хранятся отдельно в папке `_max_import`.

## Шаг 1. Что нужно подготовить заранее

1. **Node.js версии 20 или выше** — скачать с [nodejs.org](https://nodejs.org/) (LTS-версия).
   Проверить установленную версию в терминале:
   ```powershell
   node -v
   ```
   *(Устанавливать дополнительные пакеты через `npm install` не нужно — проект работает на встроенных модулях Node.js.)*

2. **Корневой сертификат Минцифры РФ** — нужен для защищённого подключения к API MAX (`platform-api2.max.ru`):
   * Скачайте файл `Russian_Trusted_Root_CA.cer` со страницы [gosuslugi.ru/crt](https://www.gosuslugi.ru/crt) и положите его в корень папки проекта.
   * Откройте его в Блокноте: если текст начинается с `-----BEGIN CERTIFICATE-----`, всё готово. Если внутри нечитаемые символы (бинарный формат), выполните в PowerShell:
     ```powershell
     certutil -encode Russian_Trusted_Root_CA.cer Russian_Trusted_Root_CA.pem
     ```
     *(и дальше указывайте `.pem` вместо `.cer`).*

3. **Бот в MAX:**
   * Создайте бота в MAX и получите его **токен**.
   * Добавьте бота в нужный канал MAX **администратором** с правом публикации сообщений.

## Шаг 2. Как выгрузить историю канала из Telegram

Выгрузка делается через компьютерное приложение **Telegram Desktop** (в мобильной и веб-версии этой функции нет):

1. Откройте нужный канал в **Telegram Desktop**.
2. Нажмите три точки (`⋮`) в правом верхнем углу → **Export chat history** («Экспорт истории чата»).
3. **Выберите нужные типы медиа** (галочки):
   * `Photos` (Фотографии)
   * `Video files` (Видео)
   * `Files` (Документы, если есть в канале)
   * `Voice messages` / `Round video messages` (если нужны)
   * *Стикеры можно не выбирать — MAX не принимает формат `.tgs`.*
4. **Обязательно сдвиньте ползунок `Size limit` (Лимит размера файла):**
   * По умолчанию Telegram ставит маленький лимит (например, 8 МБ), из-за чего видео не скачаются.
   * Выставьте ползунок на **250 МБ** (это лимит видео в MAX) или выше.
5. **Формат выгрузки (очень важно!):**
   * Нажмите на строчку `Format: HTML` и переключите на **`Machine-readable JSON`**.
   * В HTML-формате скрипт архив не прочитает!
6. Нажмите **Export** и дождитесь завершения.
   * Если на каком-то файле выгрузка надолго зависла, можно нажать «Пропустить» — скрипт аккуратно отметит такой файл в логе `failed.json`, не останавливая перенос.
7. В итоге получится папка (например, `ChatExport_2026-11-24`), внутри которой лежит файл **`result.json`** и подпапки `photos/`, `video_files/`, `files/`.
   * **Важно:** не перемещайте `result.json` отдельно от папок с фото и видео — они должны лежать вместе.

## Шаг 3. Настройка файла `.env`

1. Скопируйте файл `.env.example` и переименуйте копию в **`.env`** (без `.example`).
2. Откройте `.env` в любом текстовом редакторе и заполните поля:

```env
# Токен вашего бота в MAX (без слова Bearer)
MAX_BOT_TOKEN=ваш_токен_сюда

# ID канала в MAX (как узнать — см. Шаг 4)
MAX_CHANNEL_ID=пока_оставьте_пустым_или_впишите_id

# Актуальный адрес API MAX
MAX_API_BASE_URL=https://platform-api2.max.ru

# Полный путь к папке с выгрузкой Telegram (внутри должен лежать result.json)
# На Windows используйте обычные слеши / и оборачивайте путь в кавычки
ARCHIVE_DIR="D:/Telegram/ChatExport_2026-11-24"

# Пауза между постами в миллисекундах (2000 = 2 секунды)
DELAY_MS=2000

# Добавлять ли в конец поста дату из Telegram (true / false)
ADD_DATE_FOOTER=true

# Отсечка по дате (необязательно): посты с этой даты и новее НЕ будут отправляться.
# Удобно, если свежие посты уже перенёс другой инструмент авторепоста.
# Формат: YYYY-MM-DD (оставьте пустым, чтобы перенести всю историю)
UNTIL_DATE=
```

## Шаг 4. Подключение сертификата и проверка бота

Откройте терминал в папке проекта.

**В Windows (PowerShell):**
```powershell
cd d:\dev\tg-to-max
$env:NODE_EXTRA_CA_CERTS="d:\dev\tg-to-max\Russian_Trusted_Root_CA.cer"
```

**В macOS / Linux:**
```bash
cd /путь/к/tg-to-max
export NODE_EXTRA_CA_CERTS="./Russian_Trusted_Root_CA.cer"
```

> **Обратите внимание:** если вы закрыли окно терминала и открыли новое, команду с `NODE_EXTRA_CA_CERTS` нужно выполнить снова перед запуском скрипта.

### Проверка связи и получение ID канала
Выполните:
```powershell
npm run check
```
Скрипт проверит сертификат, токен и покажет `chat_id` каналов, в которые добавлен бот (у каналов ID обычно **с минусом**, например `-81607603261462`).
*(Если список пуст — удалите бота из канала и снова добавьте администратором, затем повторите `npm run check`.)*

Скопируйте найденный `chat_id` в поле `MAX_CHANNEL_ID=` файла `.env` и отправьте 1 пробный пост:
```powershell
npm run check -- --send-test
```
Убедитесь, что сообщение «Тест связи пройден!» появилось в канале MAX.

## Шаг 5. Варианты запуска переноса

### 1. Пробная проверка архива без отправки (`dry-run`)
Рекомендуется запускать перед каждым переносом:
```powershell
npm run dry-run
```
Скрипт **ничего не публикует**, а проверяет весь архив и выводит:
* сколько записей Telegram склеилось в посты и сколько из них альбомов;
* все ли файлы на месте и нет ли видео тяжелее лимита MAX (250 МБ);
* ориентировочное время переноса.

### 2. Тестовый запуск нескольких постов (`--limit`)
Отправляет первые 10 постов и останавливается, запомнив место остановки:
```powershell
npm run test10
```
Или любое другое количество (например, 5 постов):
```powershell
npm start -- --limit 5
```
При следующем запуске скрипт автоматически продолжит со следующего поста.

### 3. Полный запуск до конца
```powershell
npm start
```
> **Совет для Windows:** при длинном переносе (1–3 часа) временно отключите автопереход компьютера в спящий режим. Даже если ПК уснёт или пропадёт интернет, при повторном `npm start` скрипт спокойно продолжит с места остановки.

### 4. Выборочный диапазон по ID сообщений из Telegram
Если нужно перенести или дозалить конкретный отрезок (ID видно в конце ссылки на пост в Telegram, например `t.me/channel/150`):
```powershell
npm start -- --from-id 150 --to-id 200
```

### 5. Как остановить и продолжить позже
Нажмите **`Ctrl+C`** в терминале один раз. Скрипт доделает текущий пост, сохранит позицию и корректно остановится. Чтобы продолжить позже — просто снова введите `npm start`.

## Где хранятся логи и как начать заново

Внутри вашей папки экспорта Telegram автоматически создаётся подпапка:
```text
<папка_экспорта>/_max_import/channel_<ID_канала>/
├── state.json    # ID последнего отправленного поста и счётчики
├── import.log    # Подробный лог каждого отправленного поста
└── failed.json   # Список пропущенных/неотправленных файлов и постов (если были)
```

* **Как сбросить прогресс и начать заново** (например, если вы очистили тестовый канал): удалите файл `state.json` (или всю папку `_max_import`).
* **Как перенести второй канал:** просто впишите в `.env` новые `MAX_CHANNEL_ID` и `ARCHIVE_DIR` (и при необходимости новый токен). Для каждого канала прогресс и логи ведутся отдельно и не пересекаются.
* **Как поделиться инструментом с друзьями:** передайте папку проекта **без файла `.env`** — друзья скопируют `.env.example` → `.env` и впишут свои данные.

## Частые вопросы

* **Ошибка TLS / сертификата при запуске:** вы забыли задать переменную `$env:NODE_EXTRA_CA_CERTS=...` в текущем окне терминала, либо файл `.cer` находится в бинарном формате (см. Шаг 1).
* **Файл `result.json` не найден:** проверьте путь `ARCHIVE_DIR` в `.env`. Он должен вести прямо в папку, где лежит `result.json`, а не на уровень выше.
* **В `failed.json` попало видео > 250 МБ:** это ограничение MAX Bot API. Сожмите такое видео вручную и загрузите в канал напрямую.
